# Robustness-of-Graph-Neural-Networks-for-Graph-Classification-Under-Structural-Perturbations

My project focuses on studying how robust Graph Neural Networks (GNNs) are for graph classification when changes are made to the structure of a graph. In class, we learned that GNNs use neighborhood aggregation to learn node embeddings, which can then be combined to make predictions about an entire graph. However, since this process depends on the connections between nodes, adding or removing edges could affect the embeddings and ultimately change the model's classification. I plan to investigate how different levels of structural perturbations affect classification accuracy and compare the performance of different GNN architectures.

This problem is important because GNNs rely heavily on graph structure to learn meaningful representations. As we discussed in class, properties such as node degree, clustering coefficients, and neighborhood relationships help describe a graph's structure. When edges are added or removed, these properties can change and potentially affect what the model learns. By studying how GNNs respond to these changes, I hope to better understand how reliable different architectures are and whether they can maintain accurate predictions when the graph structure is incomplete or contains noise.
